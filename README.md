# ai-design-style-catalog 🎨

**「AIにホームページを作らせたい。でも"あの感じ"にはしたくない。」**

AI（ChatGPT / Claude / Gemini / Cursor 等）にデザインを指示するための**スタイルカタログ**です。
スタイルを選ぶとプレビューとプロンプトが表示され、コピーしてそのままAIに渡せます。

🔗 **デモ**: https://keima-tech.github.io/ai-design-style-catalog/

---

## これは何？

「おしゃれにして」「モダンな感じで」という指示はAIに通りません。
デザインには**名前**があります（ミニマリズム、スイススタイル、ネオブルータリズム……）。
このカタログは、その名前と視覚プレビュー、そして**そのまま使える指示文（プロンプト）**を結びつける道具です。

- 🎨 **30スタイル**収録（ミニマル / トレンド / ボールド / 上質 / ナチュラル）
- 📄 **3成果物**に対応（ホームページ / Webアプリ / スライド）— プレビューもプロンプトも連動
-  **「AIが作った感」脱却ガイド**付き（紫グラデ＋ガラス＋等幅3カード…の定番を禁止する指示を自動追記）
- 🎛 **スタイルMIX**機能（ベース70%＋別スタイル30%の合成プロンプトを生成）
- 📦 **依存ゼロのHTML1枚**。ビルド不要、オフライン動作、クローンして開くだけ

## 使い方

1. **成果物を選ぶ** — ホームページ / Webアプリ / スライド の大きなカードで選択
2. **スタイルを選ぶ** — カードをクリックすると拡大プレビューとプロンプトが表示
3. **情報を埋める** — 「サイトの目的」「ブランド名」など（成果物に応じてラベルが変わります）
4. **コピーしてAIに貼る** — 出来上がりが違えば「プレビューを見ながら調整して」と追撃

## 🚫 「AIが作った感」脱却ガイド

チェックした項目が**すべてのプロンプトに自動追記**されます（デフォルト5項目ON）。

- 紫→青グラデ＋ガラス風パネルの定番コンビを禁止
- 等幅3枚並びの特徴カードを禁止
- 「革新的なソリューション」等の汎用コピーを禁止
- 絵文字アイコンを禁止（SVG or テキストラベル）
- 全面センター揃えを禁止（意図的な非対称を）
- ほか：書体ペアリング / 写真ディレクション / 微細部の作り込み 等 全8項目

> スタイル選びより、このガイドのほうが「AI臭さ」には効きます。ONのままのご利用を推奨。

## 🎛 スタイルMIX

「ベース：ミニマリズム ＋ 取り入れ：バウハウス（配色・装飾のみ）」のように、
**2スタイルを20〜30%の比率で混ぜる**プロンプトを生成。取り込む要素（配色/タイポ/レイアウト/装飾/ムード）をチェックで選択できます。

## スタイルを追加したい方へ

`index.html` 内の `STYLES` 配列に1オブジェクト追加し、同名のCSSクラスを書くだけです。

```js
{id:'mystyle', nameJa:'マイスタイル', nameEn:'My Style', cat:'trend',
 tags:['タグ1','タグ2'], desc:'カード用の短い説明',
 aiNote:'そのスタイルが陥りやすいAI臭と回避策',
 prompt:'■ デザイン方針\n・配色：…\n・フォント：…\n・レイアウト：…\n・印象：…'}
```

```css
.mystyle{--bg:#fff;--fg:#111;--accent:#f00;--r:12px; /* 背景/文字/アクセント/角丸 */}
.mystyle .m-card{/* プレビュー用モックの各部（.m-card .m-btn .m-title 等）を上書き */}
```

プレビューは `.m-*` クラスで組まれたモックにスタイル変数（`--bg --fg --accent --line --card --r` 等）を流し込む仕組みなので、**変数を置くだけで3成果物すべてのプレビューに反映**されます。PR歓迎です。

## FAQ

**Q. どのAIで使えますか？**
A. テキストとして渡せるものなら何でも。ChatGPT / Claude / Gemini / Copilot / Cursor 等で動作確認を想定。

**Q. プロンプトは編集できますか？**
A. はい。モーダル内のテキストエリアは直接編集可能（編集後は自動反映より手編集が優先されます）。

**Q. 商用利用は？**
A. MITライセンスの範囲で自由にご利用ください。生成プロンプトの利用に制限はありません。
